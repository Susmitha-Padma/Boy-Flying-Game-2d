# Boy-Flying-Game-2d
#RULES OF GAME
-> If you touch right side of the screen then the flight will shoot the bullets. 
-> If you touch left side of the screen then we can control the flight to move up and down.
-> If the boy misses any bird to kill (Or) bird passes through the boy side then the game will be over.
-> If the flight boy and flying bird collide (Or) hit each other then also game will be over.
